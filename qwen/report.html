1. Approach & Pipeline

We probe Gemma 2B's internal representations using Gemma Scope Sparse Autoencoders (SAEs). The core question: can we learn a human-readable Boolean circuit that separates harmful from benign text?

Stage 1 — SAE Feature Classifiers

We extract binary SAE firing vectors: for each example, each of the 16,384 SAE features is either active (fired somewhere in the sequence) or not. We then rank features by Δ = P(fires | harmful) – P(fires | clean) and train a differentiable logic gate network (difflogic) on the top-k features.

Stage 2 — End-to-End Distillation

We bypass the SAE entirely and learn Boolean circuits from raw hidden-state neurons. Each SAE feature is approximated by a small Boolean circuit, then all feature circuits are stacked and jointly fine-tuned against the label.

difflogic trains a network of differentiable logic gates (AND, OR, XOR, XNOR, NOT, implication, …) using gradient descent with temperature annealing. At evaluation time the soft gates are snapped to their nearest hard Boolean operation, yielding an exact, human-readable Boolean formula.

3. Jailbreak Dataset — New Experiments

Dataset: GuardrailsAI/detect-jailbreak. Task: classify whether a user prompt is a jailbreak attempt. Split: 1000 discovery per class, 500 eval per class.

Why jailbreak detection is harder than toxicity
Jailbreak prompts are often syntactically clean — they use roleplay personas ("DAN", "Illegality Mode"), fictional framing, or instruction injection rather than explicit offensive language. The harmful intent is distributed across the full prompt, not localised to a few toxic tokens.

5. New Training Paradigm

The jailbreak experiments exposed three weaknesses in the original training loop. We introduced three improvements now applied to all datasets:

1
Best-weight tracking Temperature annealing causes F1 to peak early then degrade as gates become over-binarised. We now checkpoint copy.deepcopy(model.state_dict()) every time eval F1 improves, and restore the best weights at training end.
Impact: F1 0.742 → 0.756 on jailbreak (restored vs last-epoch weights).
2
Cosine LR annealing CosineAnnealingLR(optimizer, T_max=epochs, eta_min=lr × 0.05) smoothly decays the learning rate to 5% of its initial value, preventing late-training oscillations that corrupt the soft gate distributions before hard snapping.
3
Two-stage evolutionary search (Phase 3) After gradient training ends, we run a discrete optimisation over the gate type assignments:

Stage A — Random multi-gate mutation

  • Each iter: randomly pick k=2–10 gates
  • Assign random gate types from 16 options
  • Accept if eval F1 improves (1 GPU forward pass/iter)
  • 3000 iterations, ~23 iter/s on GPU
  • Addresses GPU underutilisation of pure greedy search

Stage B — Greedy polish

  • For every gate: try all 16 types, keep best
  • Up to 5 passes, early-stop if no improvement
  • ~32,752 evals per pass
  • Guarantees local optimality in gate-type space
Stage A: 11/3000 mutations accepted → F1: 0.756 → 0.777 (130s at 23 iter/s)

Key Findings

1. Boolean circuits match soft classifiers on toxicity. Difflogic F1=0.893 ties logistic regression at top-8 while providing a human-readable 3-gate formula.
2. Jailbreak is fundamentally harder. The MLP ceiling at layer 20 is F1=0.878; difflogic reaches 0.833. The gap is smaller than for toxicity, suggesting less discriminative information is available in the representation.
3. Layer 25 SAE features are better for jailbreak. Top-32 difflogic improves from 0.819 (layer 20) to 0.833 (layer 25). Intent-level semantics crystallise in deeper layers.
4. Distillation works. End-to-end Boolean circuits from raw neurons reach F1=0.851 (toxicity) and 0.790 (jailbreak) — competitive with SAE-based classifiers, with no SAE needed at inference.
5. Jailbreak circuits are sparser. Where toxicity produces rich 3–5 feature circuits, jailbreak converges to 1–3 features — reflecting the concentrated signal of a single dominant jailbreak-type SAE feature.
